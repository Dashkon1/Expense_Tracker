Описание программы «Expense Tracker»
Автор: Дарья Дядькина

Краткое описание
Это простая программа для учета расходов, выполненная на языке Python с использованием библиотеки Tkinter. Она позволяет вводить расходы, сохранять их, фильтровать по категории и датам, а также подсчитывать общую сумму затрат. Всё это — через удобный графический интерфейс.

Инструкция по запуску
Требования
Установленный Python (версия 3.6 и выше). Скачать можно с официального сайта Python.
Установка зависимостей
В этой программе используется стандартная библиотека Python, поэтому дополнительные установки не нужны.
Запуск программы
Скопируйте весь код программы в файл с расширением .py, например, expenses.py.

Откройте командную строку или терминал.

Перейдите в папку, где находится файл:

bash

cd путь\к\папке
(замените путь\к\папке на реальный путь).

Запустите программу командой:
bash

python expenses.py
Примеры использования и работы программы
Добавление расхода:

Введите сумму расхода, например, 150.50 в поле «Сумма».
Введите категорию расхода, например, «Продукты».
Укажите дату в формате ГГГГ-ММ-ДД, например, 2024-04-27.
Нажмите кнопку «Добавить».
Просмотр расходов:

После добавления расходы появятся в таблице ниже, показывая сумму, категорию и дату.
Фильтрация:

Введите категорию для фильтрации, например, «Продукты» или оставьте пустым.
Введите дату в формате ГГГГ-ММ-ДД, чтобы увидеть расходы за конкретный день, или оставьте пустым.
Нажмите «Показать» — таблица обновится, показывая только выбранные расходы.
Чтобы сбросить фильтр и вернуть все записи, нажмите «Сброс».
Общая сумма:

Внизу отображается общее количество всех расходов или выбранных по фильтру.
